> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three visual improvements to the desktop leaderboard and search UX: wider resizable panel, more prominent search box, and scroll-to-selected in the leaderboard list.

**Architecture:** All changes are contained to two files — `index.css` for style tokens and the resize handle rule, and `LeaderboardPanel.jsx` for the drag interaction and scroll-to-selected behavior. No new files, no new components, no new props to App.jsx.

**Tech Stack:** React 19, Vite 5, plain CSS (no CSS-in-JS), MapLibre GL JS (unaffected)

## Task 2: Drag-to-resize leaderboard panel

**Files:**
- Modify: `web-app/src/index.css`
- Modify: `web-app/src/components/LeaderboardPanel.jsx`

- [ ] **Step 1: Add resize handle CSS**

In `web-app/src/index.css`, add these rules immediately after the `.leaderboard-panel--inline` block (around line 294):

```css
.lb-resize-handle {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  width: 4px;
  cursor: col-resize;
  background: rgba(155,252,150,0.10);
  z-index: 10;
  transition: background 0.15s;
  flex-shrink: 0;
}
.lb-resize-handle:hover,
.lb-resize-handle:active {
  background: rgba(155,252,150,0.28);
}
```

- [ ] **Step 2: Add width state and drag handler to LeaderboardPanel**

In `web-app/src/components/LeaderboardPanel.jsx`, add `useRef` to the existing import:

```js
import { useMemo, useState, useRef, useCallback } from 'react'
```

Then, inside the component body (after the existing `useState` calls), add:

```js
const DEFAULT_WIDTH = 260
const [width, setWidth] = useState(DEFAULT_WIDTH)

const handleDragMouseDown = useCallback((e) => {
  e.preventDefault()
  const startX = e.clientX
  const startWidth = width

  function onMouseMove(e) {
    const newWidth = Math.max(180, Math.min(440, startWidth + (e.clientX - startX)))
    setWidth(newWidth)
  }

  function onMouseUp() {
    window.removeEventListener('mousemove', onMouseMove)
    window.removeEventListener('mouseup', onMouseUp)
  }

  window.addEventListener('mousemove', onMouseMove)
  window.addEventListener('mouseup', onMouseUp)
}, [width])
```

- [ ] **Step 3: Apply width and render the drag handle**

In the JSX return, find the root div:

```jsx
<div className={`leaderboard-panel${inline ? ' leaderboard-panel--inline' : (isOpen ? '' : ' leaderboard-panel--closed')}`}>
```

Change it to:

```jsx
<div
  className={`leaderboard-panel${inline ? ' leaderboard-panel--inline' : (isOpen ? '' : ' leaderboard-panel--closed')}`}
  style={!inline ? { '--lb-w': `${width}px` } : undefined}
>
```

Then, immediately after that opening div (before `<div className="lb-inner">`), add the resize handle — but only for the non-inline variant:

```jsx
{!inline && (
  <div className="lb-resize-handle" onMouseDown={handleDragMouseDown} />
)}
```

- [ ] **Step 4: Verify visually**

In the browser (desktop):
- Hover over the right edge of the leaderboard panel — a faint green strip should appear
- Click and drag the right edge left and right — the panel should resize smoothly between ~180px and ~440px
- Neighborhood/street names in the `.lb-name` column should expand as the panel widens (they already have `flex: 1`)
- Close and re-open the panel (rail icon) — the slide animation should still work correctly and the panel should reopen at the dragged width
- Reload the page — width should reset to 260px

The mobile sheet leaderboard (inline mode) should be unaffected.

- [ ] **Step 5: Commit**

```bash
git add web-app/src/index.css web-app/src/components/LeaderboardPanel.jsx
git commit -m "Add drag-to-resize handle on leaderboard panel (180–440px)"
```

## Task 3: Scroll leaderboard to selected boundary on map click

**Files:**
- Modify: `web-app/src/components/LeaderboardPanel.jsx`

- [ ] **Step 1: Add listRef and scroll effect**

`useRef` is already imported from Task 2. Inside the component body, add a ref for the scroll container and a scroll effect:

```js
const listRef = useRef(null)

useEffect(() => {
  if (!selectedFeatureName || !listRef.current) return
  const escaped = CSS.escape(selectedFeatureName)
  const el = listRef.current.querySelector(`[data-name="${escaped}"]`)
  if (el) el.scrollIntoView({ behavior: 'smooth', block: 'center' })
}, [selectedFeatureName])
```

Add `useEffect` to the existing React import at the top of the file:

```js
import { useMemo, useState, useRef, useCallback, useEffect } from 'react'
```

- [ ] **Step 2: Attach listRef to the scroll container**

Find the `<div className="lb-inner">` element and add the ref:

```jsx
<div className="lb-inner" ref={listRef}>
```

- [ ] **Step 3: Add data-name attribute to each list row**

Find the list row div inside the `displayedRanked.map(...)` call:

```jsx
<div
  key={row.name}
  className={`lb-list-row${isSel ? ' lb-list-row--selected' : ''}`}
  onMouseEnter={() => handleRowEnter(row)}
  onMouseLeave={onHoverEnd}
  onClick={() => onFeatureSelect(row.name)}
>
```

Add `data-name={row.name}` so the effect can locate it:

```jsx
<div
  key={row.name}
  data-name={row.name}
  className={`lb-list-row${isSel ? ' lb-list-row--selected' : ''}`}
  onMouseEnter={() => handleRowEnter(row)}
  onMouseLeave={onHoverEnd}
  onClick={() => onFeatureSelect(row.name)}
>
```

- [ ] **Step 4: Verify visually**

In the browser (desktop, neighborhoods layer):
- Click a neighborhood boundary on the map — the leaderboard should smoothly scroll to that row and show it centered in the list
- Click a different boundary — list should scroll to the new selection
- Use the search box to select a boundary — list should also scroll to it
- Click a leaderboard row directly — list scrolls to center it (may only move slightly if it was near-visible already, which is fine)
- Switch to the streets layer and click a street — same behavior; if the street is beyond rank 1,000 and not rendered, the scroll silently does nothing
